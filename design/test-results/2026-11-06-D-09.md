# D-09: opening a library from other apps – 2026-11-06

Device test D-09 (`design/test-plan.md` section 4; architecture A-24; assessment SP-37) on the A52: the shared test library `valid-signed.zbl` (`android/core/testing/src/main/resources/conformance/packages/`) sent through each channel, then tapped in that app and shared from it to Zangbundel. The owner sent the file and tapped; the intents were read from the phone's log (`ActivityTaskManager: START`), which shows action, type and the address's authority. **Result: *Delen → Zangbundel* works from every channel that offers Share to other apps (WhatsApp, Chrome, *Mijn bestanden*). A tap opens Zangbundel in no channel. Signal and Gmail offer no Share for attachments. Telegram, Discord and Quick Share were not tried.**

| Field | Value |
|---|---|
| Build | debug build of `main` at `c5d1d03` (versionName `0.3.0`, package `nl.pe1mew.zangbundel.app.debug`) |
| Phone | Samsung Galaxy A52, Android 14 |
| Library | `valid-signed.zbl`, signed with the RFC 8032 test key, version 1. The phone had version 4 of the same library, signed with a second test key, so every successful import asked M-70 with the version sentence; each was cancelled. |

## What this means

- **No channel passes the file name or the library type on a tap.** WhatsApp, Gmail and Chrome use addresses without the file name and a generic type (`application/zip`, `application/octet-stream`). Signal sends no type at all, and Samsung's file manager sends no intent. The by-name filter (`pathSuffix .zbl`) and the library-type filter (architecture A-24) therefore never match on this phone. Only a filter for every ZIP or every unknown file would, which the approved proposal ruled out (section 3.2). The filters stay: they cost nothing and serve a channel that does keep the name or type.
- **Share is the route that works.** It works directly from WhatsApp, Chrome and the file manager. From Signal and Gmail the user saves or downloads the file first, then shares it from *Mijn bestanden* or opens it with *Bibliotheek toevoegen → uit een bestand*.
- **The wiki manual should say so before the release.** *Delen → Zangbundel*, or save the file first, then *Delen* from the file manager. Tapping a library file in a chat does not open Zangbundel.

The files the channels saved stay on the A52 (WhatsApp's documents folder, `Download/Signal/`, `Download/`); they are the owner's to remove.
