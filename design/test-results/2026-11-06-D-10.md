# D-10: the update check on *Over* – 2026-11-06

The first run of the update check (FR-GEN-09, guiDesign D-86, architecture A-25) on a phone, against the real GitHub release. **Result: D-10 passes in part.** The three answers a phone installed by cable can give were checked: the latest version, a newer version with the download page, and GitHub not reachable. Still open: the Play and F-Droid buttons, which need a phone that installed the app from those stores; a build newer than the latest release (unit tests only); and the packet capture.

| Field | Value |
|---|---|
| Scenario | D-10 (`design/test-plan.md` section 4) |
| Build | debug build of the working tree (versionName `0.3.0`, versionCode 2026110301, package `nl.pe1mew.zangbundel.app.debug`), and the same build with versionName set to `0.2.0` for one step; `app/build.gradle.kts` restored afterwards, unchanged |
| Phone | Huawei Mate 20 Lite, Android 10, installed by `adb install`, so Android names no installer |
| Network | The phone's Wi-Fi, then Wi-Fi and mobile data switched off (`svc wifi disable`, `svc data disable`) and on again |
| GitHub | `releases/latest` was `v0.3.0` (published 2026-11-03) |
| Participants | None but the developer's tools: taps by `adb shell input`, texts read with `uiautomator dump` |

## Results

| Step | Pass criterion | Result |
|---|---|---|
| Before the tap | Button *Zoeken naar een nieuwe versie*, line *Hiervoor is internet nodig.* | Pass: both shown directly under the version tile |
| 0.3.0 installed, online | Says the user has the latest version | Pass: *Je hebt de nieuwste versie, 0.3.0.*, about 6 s after the tap or sooner (read after a fixed 6 s wait); no store button |

| No Wi-Fi, no mobile data | Says GitHub is not reachable within 15 s | Pass: *GitHub is niet bereikbaar. Controleer de internetverbinding en probeer het opnieuw.*, read 7 s after the tap |

| F-Droid install | *Openen in F-Droid* opens the F-Droid page | Not run: the app is not on F-Droid yet |
| Build newer than the release | *Jij hebt …; de laatste uitgave is …* | Not run on a phone; covered by `AppUpdateCheckTest` |
| Packet capture | One connection, to `api.github.com`, none before the tap | Not run |
