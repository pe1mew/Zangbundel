# R8 9.1.57 over AGP 8.13.2's own R8 – 2026-10-27

Architecture A-19 as of v0.21. `bundleRelease` on the owner's machine printed about 150 warnings *An error occurred when parsing kotlin metadata*: AGP 8.13.2 bundles R8 8.13, and Kotlin 2.4 needs R8 9.1.29 or newer (developer.android.com/build/kotlin-support). The app does not read Kotlin metadata at run time (no `kotlin-reflect`), and the release-configured fieldtest build had run all day, so nothing visible was wrong; the warnings meant R8 left the metadata unshrunk. **Result: with R8 9.1.57 pinned on the build classpath the warnings are gone, and the release configuration works on the phones.**
